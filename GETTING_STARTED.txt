ShopEase — Assignment 2 Android Studio Project (Java + XML)

This project extends the same ShopEase app from Assignment 1.
Existing Splash, Login, Sign Up and Firebase client configuration are preserved.
New screens: product grid, product detail, shopping cart, COD checkout.

App package: pk.edu.nfciet.shopease
Compiled for Android SDK 36, minimum supported SDK 26.
App version: 2.0

IMPORTANT: Products must be created in the user's FIRESTORE CONSOLE and
firebase.rules must be published there. The ZIP cannot remotely mutate the
owner's Firebase project and does not include a Firebase Admin key.

Includes the original Android Studio Gradle files, full Java/XML app, rules,
8-item seed data, source verification script, and setup instructions.
No GitHub push/commit and no production APK were generated in this environment.
